# Integrated Nicole review candidate

Nicole is a single assistant across NaS. The account greeting uses the signed-in first name; the sidebar shows the full account name. The workspace input opens the expanded /nicole route; the global Ask Nicole control opens the same conversation in a side panel. Named folders and conversations are saved in an account-owned Supabase library with RLS. The full page and side panel share the same selected conversation. A tab cache preserves pending edits through full article navigation and is cleared on sign-out. Version checks reject stale writes rather than silently overwriting changes from another device; the UI offers an unsaved JSON download and reload recovery. Libraries are bounded at 30 folders, 100 conversations, 20 messages per conversation and 1.5 MB validated payload. Users can rename, move and delete conversations, and remove folders while retaining conversations. Google account pictures use an explicit HTTPS host allowlist and no referrer; other accounts or failed images use initials. Profile metadata never authorizes access.

The real server-side OpenAI Responses integration uses OPENAI_API_KEY and the fixed gpt-6-luna model only; there is no model override or fallback. No key is bundled into client code. Authentication, canonical/host-bound preview origin checks, account identity checks, bounded input/output and atomic per-account usage counters precede paid API requests. The model receives only the conversation, public search metadata and an optional explicitly selected public page excerpt. Saved notes and account data are not sent. Responses use store:false; this is not a promise of zero provider retention.

The private quota table stores no conversations. Limits are 20 requests per five minutes and 100 per day per account. Only the private, fixed-purpose function can change counters; callers cannot read or reset them. The public RPC wrapper is SECURITY INVOKER. Authenticated scope and auth.uid() are checked before quota updates. Schema changes were installed on NaS Workspace; rollback-only tests verified caps and grants. Existing unrelated database advisor findings remain unchanged.

/account/preview contains sample account content and is available only for local development or Netlify deploy-preview builds. Production returns 404. Real /account remains authenticated. The preview does not bypass authentication for paid Nicole requests. Release approval is recorded separately.
